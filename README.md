# bayesian-media-mix-modelling
Bayesian MMM using PyMC, Ridge Regression and FMCG sales data
Bayesian Media Mix Modelling (MMM) for FMCG

This project demonstrates an end-to-end Media Mix Modelling workflow using Python to analyse FMCG product sales, demand drivers and advertising effectiveness.

Dataset

169 weeks of FMCG example data, two competitors, seven media channels, weather and pricing variables, and sales measured in kilograms.

Methodology

EDA → Feature Engineering → Ridge Regression → Adstock and Saturation → Bayesian Modelling (PyMC) → Model Validation → Media Attribution and ROAS.

Technologies

Python, pandas, NumPy, scikit-learn, PyMC, ArviZ, Matplotlib, Seaborn and statsmodels.
